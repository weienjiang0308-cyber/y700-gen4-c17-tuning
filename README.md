# y700-gen4-c17-tuning

专为刷了 **ColorOS 17（OPD2515 移植底包，如咕咕 C17 包）** 的 **联想拯救者 Y700 四代（TB322FC，骁龙 8 Elite）** 打造的 Root 修复补丁与实用模块合集。

> **零外部依赖 · 全内存无损运行**：所有模块均支持 **KernelSU / Magisk / APatch**，自带 `skip_mount`，不依赖 `meta-overlayfs`、不依赖 LSPosed。全部修改仅通过内存挂载（`mount --bind` / `tmpfs`）、`resetprop` 与系统动态资源覆盖（`FabricatedOverlay`）生效，**绝不改动系统只读分区**；禁用或卸载模块后重启即 100% 恢复原厂。

## 一、`y700g4_c17_fix` · 拯救者 Y700 四代 C17 终极修复补丁（v2.5）

### 解决的六大痛点 Bug

1. **修复刷新率乱跳 60Hz、亮屏瞬间掉帧、切窗口掉帧与待机耗电**
   - **原包问题**：移植包自带刷新率调度会在切应用、负一屏滑动甚至停手时莫名掉到 60Hz，或装了 Scene 互相抢控制权导致闪跳 60Hz。
   - **补丁效果**：底层接管并关掉 ColorOS（`touch_idle` / `refreshrate_director` / `ovfr` / 2100+ 条应用限帧表）与高通动态降帧机制，锁定系统高刷档位 `3` 并开机自动屏蔽 Scene 刷新率抢帧：
     - **触屏点击、手写笔书写、按音量键、按电源键息屏/亮屏、皮套/双击唤醒、旋转屏幕**：瞬间拉满 **165Hz**（转屏与亮屏唤醒均抢在动画第 1 帧前预触发并卡点补发，彻底告别 30Hz 锁屏唤醒瞬间掉帧卡顿）；
     - **看视频、信息流或列表滚动**：自动给到 **120Hz**（整除 24/30/60 帧片源不抖动）；
     - **大型游戏或 `games.txt` 名单内应用（预置 421 款）**：全程稳定 **165Hz**；
     - **抬手静置 5 秒**：直接降到 **30Hz** 省电，熄屏瞬间交还系统。守护进程跑在小核，静止期每分钟 CPU 占用不到 `0.01` 秒。

2. **修复 8×6 桌面横竖屏错位、底部页码圆点悬空、横屏压 Dock 遮挡**
   - **原包问题**：套用小尺寸底包参数导致竖屏图标区过窄与 Dock 对不齐、页码点悬在半空；横屏最后一行图标压到 Dock 栏上，竖屏握持开机再转横屏还会漏读尺寸。
   - **补丁效果**：开机赶在桌面加载前分三组（`y700_port`、`y700_land`、`y700_lau`）原子提交动态覆盖，无论竖屏还是横屏开机、怎么来回旋转都严丝合缝：
     - **竖屏**：左右边距扩至 `12dp` 与 Dock 对齐；突破 `OplusPageIndicator` 硬编码底边距限制，将页码圆点精准下移 `10dp` 居中于最后一行与 Dock 之间；
     - **横屏**：网格整体微调上移、缩小格内边距、文字微调至 `10sp`，并将页码点顶置到上方留白处；
     - **首次刷入**：支持按**音量加键**一键将桌面设为适配最佳的 `8×6` 布局（10 秒不按默认启用，后续随时可在桌面设置自由切换）。

3. **修复屏幕默认密度偏大（440）且手动改完老被重置**
   - 开机早期直接通过 `resetprop` 将出厂密度固定为最协调的 **`420`**，进系统「显示大小」也不会再被重置回 440。

4. **修复音量条跑反边弹在左侧、边距太宽、够不着实体键**
   - 底包按顶部音量键机型配置导致音量条默认弹在屏幕左边且离边缘 `34dp`。补丁自动将音量条挪回**屏幕右侧**、贴边收窄至 **`4dp`**，并在竖屏下整体上移 **`148dp`** 精准对齐机身右侧实体音量键。

5. **修复安卓 17 下 Claude、ChatGPT、Gemini 等新应用全断网**
   - 部分路由器下发全零 IPv6 前缀（`::/64`）时，安卓 17 的本地网络保护机制会把整个公网 IPv4（内部映射为 `::ffff:x.x.x.x`）误判为局域网并拦截所有 `targetSdk=37` 新应用。补丁实时监听地址变化，一旦检测到全零前缀秒关当前 Wi-Fi 的 IPv6，换到正常网络不受影响。

6. **修复后台模块偷跑超大核发热掉电 & 优化长距离网络吞吐**
   - 开机自动停掉无用的高通 Wi-Fi 诊断日志服务（`vendor.cnss_diag`），将 TCP 接收窗口放大到 `4MB / 32MB`；
   - 自动读取 `/dev/cpuset/background/cpus` 小核范围，开机及定时扫描所有已装与新刷模块的进程及**全部子线程**，统一锁进小核并降低 `nice` 优先级（保留负值高优先级线程如 `uperf` 的 `-20` 不变）。

### 安装与配置说明

1. 在 KernelSU（需管理器版本匹配内核，如咕咕 C17 V6.3 请使用 ≥32725 管理器）、Magisk 或 APatch 中刷入 zip，重启生效。
2. 所有开关与微调参数均集中在 `/data/adb/modules/y700g4_c17_fix/config.conf`（改完重启生效，升级补丁自动保留配置和 `games.txt` 游戏名单）：

| 配置项 | 默认值 | 说明 |
|---|---|---|
| `VRR` | `1` | 智能刷新率总开关（`1` 开 / `0` 关） |
| `LAUNCHER_FIX` | `1` | 8×6 桌面横竖屏适配开关 |
| `PORT_IND_DOWN_DP` | `10` | 竖屏桌面页码圆点下移距离（dp，范围 `1~12`，`0` = 不调） |
| `DENSITY` | `420` | 屏幕出厂密度（`0` = 不改） |
| `VOLUME_RIGHT` | `1` | 音量条显示在右侧（改 `0` 重启自动恢复左侧） |
| `VOLUME_MARGIN_DP` | `4` | 音量条离屏幕边缘距离（dp，`0` = 不改） |
| `VOLUME_UP_DP` | `148` | 竖屏音量条上移距离（dp，对齐实体键，`0` = 不移） |
| `IPV6_FIX` | `1` | 安卓 17 全零 IPv6 前缀断网修复开关 |
| `NET_TUNE` / `CNSS_DIAG_OFF` | `1` / `1` | TCP 接收窗口优化 / 停高通 WiFi 诊断日志服务 |
| `LITTLECORE` | `1` | 通用模块多线程自动小核化开关 |
| `TOUCH_HZ` / `IDLE_HZ` / `VIDEO_HZ` / `GAME_HZ` | `165` / `30` / `120` / `165` | 各场景目标刷新率档位（支持 `30 60 90 120 144 165`） |
| `SHOW_REFRESH` / `DEBUG` | `0` / `0` | 左上角刷新率显示 / 在 `vrr.log` 记录每次档位切换 |

- **运行日志**：同目录下的 `vrr.log`、`launcher.log`、`ipv6.log`、`net.log`、`littlecore.log`（均带自动行数轮转，不占空间）。
- **关于 `fab.dex`**：系统自带的 `cmd overlay fabricate` 只允许改整数与颜色，无法修改尺寸（`dimen`）和负值。模块内置的 5KB 小工具 `fab.dex` 由纯反射源码 [`tools/Fab.java`](tools/Fab.java) 编译而成，通过 `app_process` 调用系统 `IOverlayManager` 接口原子注册动态资源覆盖。

## 二、`adb_wifi_auto` · 无线调试安全自启（v1.2）

安卓在每次重连 Wi-Fi、切换漫游节点或重启后都会自动关掉「无线调试」；但如果无差别在任何网络下自动开启无线调试，且 adb Shell 授了 Root，出门连公共 Wi-Fi 时会有严重安全隐患。

- **白名单自动开启**：只在连上 `config.conf` 里 `HOME_SSIDS` 指定的自家 Wi-Fi（支持一行一个填写全屋漫游多个分支、支持空格与中文）时自动打开无线调试。
- **出门强制关闭（`AUTO_CLOSE_OUTSIDE=1`）**：一旦检测到连上名单外的任何外部公共 Wi-Fi，**0 秒立即关闭无线调试**；断开 Wi-Fi（预留 5 秒缓冲防家里漫游切换瞬断）确认离家后也自动关闭。
- **使用前配置**：刷入后编辑 `/data/adb/modules/adb_wifi_auto/config.conf`，把 `YOUR_HOME_WIFI_5G` 改成你自己的 Wi-Fi 名称。

## 三、`sys_apps_autostart` · 应用系统化 + 开机自启（v1.1）

- **无元模块依赖系统化**：安装时自动把当前已装的指定应用（默认 `com.omarea.vtools:Scene` 与 `com.wireguard.android:WireGuard`，含 Split APK 分包）复制进模块目录；开机 `post-fs-data` 阶段在内存 `tmpfs` 中核对合并原有 `/system/app` 应用与新应用后整体 `mount --rbind`，应用获得 `SYSTEM | UPDATED_SYSTEM_APP` 标志且不影响日常升级。
- **ColorOS 自启白名单**：自动写入并在开机后补写 `/data/oplus/os/startup/autostart_white_list.txt`，卸载自动清理。
- **WireGuard 自动连隧道**：修改 `/data/adb/modules/sys_apps_autostart/config.conf` 中的 `WG_TUNNEL` 为你的隧道名后，开机解锁联网即可自动拉起隧道；也可在 KernelSU 管理器中直接点本模块的「操作」按钮一键切换开关。
